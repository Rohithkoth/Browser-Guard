Time Guard

Set up your unlock codes

When you hit a limit, the only way past it is a 6-digit code from an authenticator app on your phone. The code changes every 30 seconds, so there's nothing to memorize.

  1. Add Time Guard to your authenticator app. Open Google Authenticator, Microsoft Authenticator, Authy or similar, choose Add account → Scan a QR code, and scan this:
    Can't scan? Enter the key instead

    Choose Enter a setup key, type Time Guard as the name, and enter this key (time-based):

  2. Enter the code your app now shows for Time Guard.

After setup, this page never shows the key again.

Daily limits

Time counts while a site is in the focused tab, or while it's playing sound. Limits reset at midnight.

These changes loosen your limits:

    Enter a code from your authenticator app to save them.

    Unsaved changes

    Adding sites, lowering limits and adding a total are always free. Raising or removing anything, or pausing, needs a code.

    Authenticator

    Moving to a new phone? Enter a code from your current app to set up the new one. The old entry stops working once the new one is confirmed.

    Lost your phone?

    There's no backdoor code. Remove Time Guard in chrome://extensions and load it again; that clears your limits and today's usage, and you set up a new authenticator.
